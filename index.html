How to set up your Google Sheet ▾
  1. Download the script — click "Download Script" above. The file is a plain text file; open it in any text editor (Notepad, TextEdit, VS Code).
  2. Create a Google Sheet — go to sheets.google.com and open a new blank spreadsheet.
  3. Open the Apps Script editor — in the spreadsheet, click Extensions → Apps Script.
  4. Replace the default code — select all text in the editor (Ctrl+A / ⌘+A), delete it, then paste the contents of the downloaded script. Save with Ctrl+S / ⌘+S.
  5. Run the setup function — in the Apps Script editor toolbar, make sure the function selector shows initializeSheets, then click the ▶ Run button. You will be prompted to authorize the script — click through to allow it to access your spreadsheet. This creates the Alternatives, Rankings, and Snapshots tabs and fills in the course example data.
  6. Deploy as a web app — still in the Apps Script editor, click Deploy → New deployment. Click the gear icon ⚙ next to "Select type" and choose Web app. Set:
    • Execute as: Me
    • Who has access: Anyone
    Click Deploy, authorize again if prompted, then copy the Web app URL.
  7. Paste the URL above and click Launch.

Tip: Each group needs their own copy of the sheet and their own deployment URL. Making a copy of the spreadsheet does not copy the deployment — you must re-deploy from each copy.
